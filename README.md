# ACCESS DENIED

A simple mystery game where players solve three questions to unlock a secret file.

## Features
- Three security questions
- Hints for the first two questions
- A hidden final message

## Built With
- HTML
- CSS
- JavaScript

## How to Play
Open `index.html` in your browser, answer the questions, and unlock the secret file.
